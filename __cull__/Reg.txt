自定义选片算法编写规范：
1. 使用 Python3 编写。
2. 为避免出现兼容性问题及方便统一，在导入模块时的导入语句按照主流推崇的导入方式编写。例如，numpy 导入为 np，导入图像数据格式时使用 from PIL import Image 等。
3. 代码中所有非选片函数的名称必须以下划线（_）开头。
4. 对选片函数规定如下（具体可参考 _.ac.py 的代码）：
    允许且仅允许 0-1 个输入，一个输出，建议通过 print 打印日志。
    输入的默认为 None，当输入为空时，输出介绍字符串，介绍字符串限一行。
    否则，接受单个 PIL.Image.Image 对象，通过计算输出 float 格式、介于 0~1 间的评分，0.0 为最差，1.0 为最优。
    选片函数名不能以下划线（_）开头，不能以 builtin_ 开头。建议以 “作者_功能” 命名。
因此，选片函数的前 2 行应为：
    def xxxauthor_xxxmethod(image: Image.Image = None) -> float | str:
        if not image: return "函数功能字符串"
5. 为便于调试，建议将选片函数中对输出影响较大的常量，以全大写的量名，单独声明在主代码之前，具体可参考 _.ac.py 的代码。
6. Python 文件的名称必须形如 A.B.ac.py 结尾，A 与 B 中仅包含大小写英文字符、数字、下划线（_）。
    其中，A 表示作者名，B 表示选片算法包的名称（概括性说明所包含选片算法的功能）。
    由于软件未来可能推出“按作者查找选片函数”等功能，建议个人或团队开发者确定一个有代表性、独特的作者名并使用之。
    文件名示例：
    GuidovanRossum.BasicFuncs.ac.py
    ysy.colorchecktools.ac.py
7. Python 文件结尾须有空行。建议在文件结尾以注释方式标明文件结束，具体可参考 _.ac.py 的代码。
